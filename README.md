# DigitalAlumni
PHP &amp; MySQL alumni system with registration, login, profiles, mutual connections, events, gallery, feedback, contact forms, and admin panel for users &amp; events. Built with PHP, MySQL, Bootstrap &amp; PHPMailer.

# Digital Alumni Portal – Parul University

A full-stack **PHP & MySQL** alumni management and engagement system built for **Parul University**.  
It allows alumni to register, manage profiles, connect with peers, view events & gallery, and submit feedback.  
Admins can manage users, events, feedback, and contact requests from a dedicated panel.

---

## Features

### User Side
- User Registration & Login
- Profile view & update (photo, company, designation, LinkedIn, etc.)
- Mutual connections (users with the same degree)
- Events listing with department filters (MCA, MBA, BBA, etc.)
- Gallery
- Feedback form
- Contact Us form
- Forgot / Reset Password (via email using PHPMailer)

### Admin Side
- Admin Dashboard
- View / Update / Delete all registered users
- Add / Update / Delete Events (with poster upload)
- View Feedback submissions
- View Contact requests
- Admin Profile

---

## Tech Stack

- **Backend:** PHP (Procedural + MySQLi)
- **Database:** MySQL / MariaDB
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Email:** PHPMailer
- **Server:** Apache (XAMPP / WAMP / Laragon recommended)

---

## Requirements

- PHP 7.4 or higher
- MySQL / MariaDB
- Apache Web Server
- XAMPP / WAMP / Laragon (recommended for local setup)
